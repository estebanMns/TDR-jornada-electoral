# @electoral/shared

Contracts that cross module boundaries (GENERAL §7). Changes here need approval
from the three owners and must be **additive**.

| File | Content |
|---|---|
| `voteOptions.ts` | Candidate and special vote option ids |
| `roles.ts` | `Role`, `JwtPayload` |
| `acta.ts` | `ActaSubmission`, `ActaReceipt`, statuses, review decisions |
| `events.ts` | `ev:all` entry format (`AccumulatedEvent`) |
| `redisKeys.ts` | Builders for **every** Redis key |
| `topics.ts` | Public topics `dep`, `mun:{id}`, `station:{id}` |
| `schemas.ts` | zod schemas for the HTTP contracts |
| `tally.ts` | Accounting rule shared by the juror app and the server |
| `catalog.json` | Generated by `pnpm seed` (do not edit by hand) |

## Naming (GENERAL.md → code)

Code is written in English. The Spanish terms of `docs/GENERAL.md` map to:

| GENERAL.md | Code |
|---|---|
| mesa / puesto / municipio / departamento | table / station / municipality (`mun`) / department (`dep`) |
| jurado / auditor / coordinador / público | `JUROR` / `AUDITOR` / `COORDINATOR` / `PUBLIC` |
| votos / sufragantes / habilitados | `votes` / `voters` / `enabled` |
| BLANCO / NULO / NO_MARCADO | `BLANK` / `NULL` / `UNMARKED` |
| `idem` | `Idempotency-Key` header |
| REGISTRADA / YA_REGISTRADA / OBSOLETA | `REGISTERED` / `ALREADY_REGISTERED` / `OBSOLETE` |
| EN_VERIFICACION / CONFLICTO / NO_REGISTRADA | `UNDER_REVIEW` / `CONFLICT` / `NOT_REGISTERED` |
| APLICADA / CORRECCION / REVERSION | `APPLIED` / `CORRECTION` / `REVERSAL` |
| `_inf` / `_suf` | `_reported` / `_voters` |
| `ts_rx`, `motivo`, `tipo` | `tsRx`, `reason`, `type` |
| topic `puesto:{id}` | `station:{id}` |
| `cat:mesa:{id}`, `jurado:{sub}:actas` | `cat:table:{id}`, `juror:{sub}:actas` |
| `aplicarResolucion` | `applyResolution` |
